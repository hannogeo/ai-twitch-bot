AI Twitch Bot

AI chat

Uses Groq to reply in your chat. Trigger by command, @mention, or reply. Automatically searches the web when it needs current info.

Web search

When someone asks a question that needs current info, the bot searches DuckDuckGo and uses the results for a better reply.

Getting started

  1. 1

    Download and run the installer.

  2. 2

    Get a free Groq API key at console.groq.com and paste it into AI Config.

  3. 3

    Get an access token at twitchtokengenerator.com (scopes: chat:read + chat:edit) and paste it into Bot Config, along with your bot username and target channel.

  4. 4

    Enter your channel name on the Dashboard and click Start Bot.
